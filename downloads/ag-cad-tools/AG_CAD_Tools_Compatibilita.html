Versione definitiva e perimetro

Rilascio autorizzato dall’autore dopo l’approvazione della RC5. Installer, Guida e menu sono stati confermati nell’ambiente AutoCAD 2027 italiano. La versione definitiva conserva la stessa logica; il confronto con la RC5 e la compilazione sono verificati automaticamente. L’approvazione non equivale a un collaudo di tutte le combinazioni elencate.

198 strumenti, 200 voci, 16 categorie, 541 nomi pubblici inclusi servizi e alias. Il manifest abilita AutoCAD completo Windows x64, serie R24.3–R26.0. AutoLISP UTF-8, DCL, CUIX e ActiveX; nessun Express Tools o runtime esterno aggiuntivo richiesto dal plugin. Restano necessari i componenti previsti da AutoCAD.

Fuori perimetro: LT, Mac/Web, altri CAD DWG, Windows 7/8/8.1, 32 bit e ARM nativo. Toolset verticali e Windows Server non sono dichiarati collaudati. Il setup è amd64, compilato con Go 1.23.2; da Go 1.21 il minimo desktop è Windows 10, ma valgono anche i requisiti AutoCAD. Il rilevamento nel registro non certifica il funzionamento.

Lingua e caricamento

Interfaccia, comandi AG_ e Guida restano italiani anche su AutoCAD inglese; i prompt Autodesk seguono la lingua del programma. Le chiamate native impiegano nomi e opzioni internazionali. I layout sono riconosciuti tramite ModelType. Queste verifiche statiche non certificano tutte le sequenze di prompt nelle diverse release.

Usare LISPSYS=1 o 2; dopo una modifica manuale riavviare AutoCAD. Nessuna variante LISPSYS=0. Il plugin non modifica SECURELOAD, LISPSYS o TRUSTEDPATHS. Il log ricevuto usa SECURELOAD=0: la prova con 1/2 non è documentata. Non è richiesto abbassare la sicurezza; in caso di avviso verificare provenienza e percorso nelle Posizioni attendibili, secondo le policy del proprio ambiente.

Riscontri nativi registrati

  • RC4: AutoCAD 2027 italiano, ACADVER 26.0s; diagnostica 198/198 funzioni e 541/541 nomi, Ribbon presente; diversi comandi provati con buon esito, senza elenco puntuale.
  • RC5: autore soddisfatto di installer, Guida e menu; autorizzazione alla versione definitiva. La schermata allegata mostra AG CAD Tools nel menu superiore e nel Ribbon.
  • Windows x64; il log NT 10.0 non distingue Windows 10/11. Edizione e build esatte non documentate. LISPSYS=1.
  • ETIT Companion, BlockHub e YQArch risultano caricati insieme; nessun collaudo esaustivo delle interazioni.
  • Il setup 2.0 ricompilato è verificato automaticamente; l’esecuzione nativa approvata riguarda la RC5, la cui logica è preservata.

Limiti delle prove

Non sono documentati collaudi nativi puntuali per tutti i 198 strumenti, AutoCAD 2024–2026, inglese, tutte le varianti WMF/font, scale Windows o tutti i casi di errore. I test automatici usano API simulate: non sostituiscono il motore geometrico Autodesk. Le singole schede illustrano i limiti operativi, ESC e UNDO.

La 2.0 è la versione definitiva autorizzata; le combinazioni non provate rimangono indicate come tali. Non è richiesta una nuova tornata di collaudo all’autore per questa promozione. Le future segnalazioni potranno ampliare il registro.
