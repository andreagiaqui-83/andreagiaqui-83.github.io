Materiale disponibile

Puoi caricare direttamente file normali o condividere un link cloud. Per le nuvole di punti è preferibile il cloud.
Carica i file disponibili

PDF, immagini, DWG/DXF, RVT, IFC, STEP/IGES, mesh e archivi ZIP.

Limiti caricamento diretto: 90 MB per file e 500 MB complessivi. Per materiale più grande usa un link cloud.

Nuvola di punti

Consigliato: condividi il link cloud alla cartella completa della nuvola nel formato originale, senza conversioni preliminari.
